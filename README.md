AXAC - Study Pro (17 mapel)
Isi: index.html, sw.js, manifest.webmanifest, ikon aplikasi, dan folder songs/ (9 lagu).
Semua file harus berada di folder yang sama. Mode offline dan "Pasang aplikasi" hanya aktif lewat https (misalnya GitHub Pages).
Fitur: halaman Materi (penjelasan saja, tombol paham di akhir topik, tersimpan otomatis), soal interaktif (jawaban tersimpan otomatis, PGK pilih 2, benar-salah), jadwal dan hitung mundur ASAS, rencana belajar harian, simulasi ujian bertimer (pilihan ganda,
pilihan ganda kompleks, benar-salah), kartu hafalan, label sumber soal, latihan acak, pencarian,
progres belajar, musik belajar, mode gelap, cadangan dan pemulihan progres.
Mapel: Pendidikan Pancasila, Bahasa Indonesia, Seni Rupa, Matematika, Al Qur’an Hadits, PJOK, IPA, SKI,
Prakarya, Bahasa Inggris, Akidah Akhlak, Bahasa Arab, Informatika, Koding, IPS, Fikih, Bahasa Jawa.
Soal berlabel "Dari soal sekolah" diambil atau diringkas dari contoh soal sekolah. Soal "Latihan AXAC"
disusun dari kisi-kisi dan sebaiknya dicek guru. Periksa kisi-kisi dan jadwal resmi sebelum dipakai.
Jadwal dihitung dalam WIB (UTC+7).

Lirik dinamis: letakkan file lirik milik Anda di folder songs/ dengan nama yang sama dengan lagunya,
misalnya 01-babydoll.lrc (berstempel waktu, baris: [00:12.50]teks) atau 01-babydoll.txt (tanpa stempel waktu).
Situs tidak menyertakan lirik apa pun. Tanpa file lirik, tombol "Cari lirik resmi" membuka situs lirik.
Mode fokus: rangkuman darurat dan materi lengkap untuk ujian terdekat, tanpa latihan, bisa dicetak.
Mapel yang ujiannya belum lewat tampil paling depan; yang sudah lewat dipindah ke belakang dan diberi tanda (waktu mengikuti jam perangkat, WIB).
Halaman Teknik belajar: ringkasan teknik belajar yang terbukti membantu, timer fokus, dan tombol ke kartu hafalan, simulasi, dan rangkuman darurat.
